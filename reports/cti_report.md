---

## 12. Limitations

The current system has several limitations:

1. The confidence score is heuristic rather than statistically calibrated.
2. CVSS severity does not represent complete real-world risk.
3. The current source set is limited primarily to CISA and NVD, with CISA KEV used for exploitation intelligence.
4. Historical analysis depends on the number and frequency of collected snapshots.
5. External API availability and rate limiting can affect enrichment.
6. The current correlation model does not yet perform advanced semantic or graph-based threat correlation.
